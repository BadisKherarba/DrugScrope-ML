1- missing data on units in activities
   - In `activities_raw.csv`, certain entries have missing or inconsistent values in the `units` and `standard_units` fields.
   - Some measurements report values in `uM` under `units` but are converted to `nM` in `standard_units`.
   - Action needed: Use `standard_units` and `standard_value` / `pchembl_value` for consistent comparison across assays.

2- Overview of Raw Data Files & Record Counts:
   - `targets_raw.csv`     : 548 rows, 4 columns (organism, pref_name, target_chembl_id, target_type)
   - `mechanisms_raw.csv`  : 610 rows, 5 columns (action_type, max_phase, mechanism_of_action, molecule_chembl_id, target_chembl_id)
   - `molecules_raw.csv`   : 407 rows, 15 columns (chembl_id, name, phase, approval, descriptors, SMILES)
   - `activities_raw.csv`  : 15,655 rows, 11 columns (assay, molecule, target, pchembl_value, activity types, values)
   - `indications_raw.csv` : 2,864 rows, 4 columns (efo_term, max_phase_for_ind, mesh_heading, molecule_chembl_id)

3- Molecules Data (`molecules_raw.csv`):
   - Total Candidate Molecules: 407
   - Approved Drugs (max_phase = 4.0): 89 molecules
   - Exploratory / Clinical Trials (max_phase 1.0 - 3.0): 318 molecules
   - Missing Data:
     * `first_approval`: 318 missing values (expected for investigational drugs not yet approved).
     * `name`: some entries only contain clinical developmental codes (e.g. AZD-7624).
   - Physicochemical Properties Available:
     * `mol_weight`, `alogp`, `hbd` (hydrogen bond donors), `hba` (hydrogen bond acceptors), `psa` (polar surface area), `rtb` (rotatable bonds), `aromatic_rings`, `ro5_violations`.
     * Lipinski's Rule of 5 violations range from 0 to 2.

4- Targets Data (`targets_raw.csv`):
   - All 548 entries are human targets (`organism = Homo sapiens`).
   - `target_type` is uniformly `SINGLE PROTEIN`.
   - Selected based on containing the keyword 'kinase' in the target name.
   - No missing values in target identifiers or preferred names.

5- Mechanisms Data (`mechanisms_raw.csv`):
   - 610 molecule-target mechanism pairs.
   - Action types filtered: INHIBITOR, ANTAGONIST, BLOCKER, NEGATIVE ALLOSTERIC MODULATOR.
   - Some molecules appear multiple times due to polypharmacology (inhibiting multiple kinase targets, e.g., ABL1, SRC, ErbB2).

6- Activities Data (`activities_raw.csv`):
   - Total rows: 15,655 bioactivity data points.
   - Types of standard measurements:
     * `IC50` (Half maximal inhibitory concentration)
     * `Ki` (Inhibition constant)
     * `Kd` (Dissociation constant)
   - `pchembl_value`: Present for all rows (ranging approximately from 4.0 to 11.5, with higher values meaning higher potency).
   - Known duplicate entries: Multiple independent publications/assays record activity for the same molecule-target pair. Aggregation (e.g., median or mean pChEMBL value) will be necessary during data preprocessing.

7- Indications Data (`indications_raw.csv`):
   - 2,864 clinical indication records mapped to candidate molecules.
   - Disease annotations provided via:
     * `efo_term` (Experimental Factor Ontology term)
     * `mesh_heading` (Medical Subject Headings)
   - Missing data observed:
     * Some rows lack standard MeSH headings or EFO mapping.
     * High concentration in oncology (non-small cell lung cancer, leukemia, neoplasms, glioblastoma).

8- Summary of Required Cleaning / Preprocessing:
   - Handle missing units by standardizing on `standard_type`, `standard_value`, and `pchembl_value`.
   - Standardize SMILES strings (sanitize using RDKit, canonicalize, strip salts).
   - Group duplicate bioassays by `(molecule_chembl_id, target_chembl_id)` and compute representative summary metrics.
   - Impute or handle missing physicochemical descriptors where applicable.
